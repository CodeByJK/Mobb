# Mobb
Vi har lärt oss att det är viktigt att man använder class eller parent elemnts för att identifiera en selector i CSS för att man annars kan påverka andra element. 

Man måste tänka på färgerna, det går inte att ha svart bakgrund och svart bild. Även länkarna måste synas mot bakgrunden.

Man behöver tänka på margins och padding så att sidan för luft och är lätt att ta till sig.
